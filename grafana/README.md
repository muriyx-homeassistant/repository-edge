# Home Assistant App: Grafana with VictoriaMetrics datasource

Grafana for Home Assistant with the official VictoriaMetrics datasource plugin preinstalled.

## About

Grafana is an analytics and visualization platform for metrics from many different sources. It can be used to build dashboards, explore time series, create alerts, and visualize data from a Home Assistant installation.

This repository is a **standalone, independently maintained fork** based on the Home Assistant Community App for Grafana. It keeps the current Home Assistant **App** structure and terminology, while adding native VictoriaMetrics datasource support.

## Fork Information

This repository is a fork maintained independently with the following additions:

- VictoriaMetrics datasource plugin integration

**Note**: Changes made in this fork are not intended to be merged back to the original repository.
